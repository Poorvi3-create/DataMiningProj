## Data Mining Project Overview

This repository bundles the assets used for a rural income segmentation study built around the "LTF Challenge" dataset. The work combines supervised learning to predict household income tiers with unsupervised clustering to surface actionable archetypes for program design.

- `dataminingproject_1.py` orchestrates the full pipeline: cleansing the Excel source, engineering features, benchmarking classifiers, adding the winning predictions to the hold-out population, and deriving cluster-level insights.
- `LTF Challenge data with dictionary.xlsx` holds the original training and scoring worksheets plus a data dictionary tab supplied by the challenge hosts.
- `final_output_compact.csv` captures the enriched scoring population with model predictions, winning label, and cluster assignments. The script also emits summary charts (`metrics_grouped_bar.png`, `clusters_stacked_income.png`, `silhouette_vs_k.png`, `corr_heatmap_top_features_clean.png`) for quick reporting.

## Getting Started

### Environment

The pipeline was tested on Python 3.10+. Create an isolated environment and install the scientific stack:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

If you do not keep a `requirements.txt`, install the needed packages manually:

```
pip install numpy pandas scikit-learn scipy matplotlib seaborn openpyxl
```

### Repository Layout

- `dataminingproject_1.py` – main execution script
- `LTF Challenge data with dictionary.xlsx` – source data (Sheet 0 = training, Sheet 1 = scoring, other tab = dictionary)
- `final_output_compact.csv` – scoring output generated by the script
- `*.png` images – visual summaries created at runtime

## Running the Pipeline

1. Ensure the Excel workbook is present. By default the script expects it at `C:\Users\Admin\Documents\GitHub\DataMiningProj\LTF Challenge data with dictionary.xlsx`. Update the `path` variable near the top of `dataminingproject_1.py` so it points to the workbook location on your machine.
2. Activate your Python environment and execute:

   ```
   python dataminingproject_1.py
   ```

3. The script prints progress updates, writes the enriched scoring file `final_output_compact.csv` alongside the Excel workbook, and generates four PNG charts summarising model quality and cluster structure.

Because the workflow uses deterministic random seeds, repeated runs with the same data will yield the same predictions and clusters.

## Methodology Summary

**Data preparation**
- Drops identifier-like columns and the target income field from the scoring sheet.
- Imputes numeric features with the median and categorical features with the mode, followed by duplicate removal.
- Encodes low-cardinality categoricals via one-hot encoding and high-cardinality categoricals with shared `LabelEncoder` fits across train/test.
- Standardises numeric fields to zero mean / unit variance for downstream models.

**Classification**
- Bins the continuous income target into four quantiles: `Low`, `Medium`, `High`, `Very High`.
- Trains `RandomForestClassifier`, `DecisionTreeClassifier`, and `KNeighborsClassifier` models with a stratified 80/20 train-validation split.
- Computes weighted accuracy, precision, recall, and F1. The best model by F1 and accuracy drives the final prediction added to the scoring data (`bestmodelpred`).

**Clustering & Insights**
- Builds thematic sub-indices (infrastructure, agriculture, wealth) from engineered features, scales them, and runs PCA for compact representation.
- Tests `k` values from 2–10 using silhouette scores, selects the best `k`, and assigns cluster labels to the scoring data.
- Calculates Cramér's V to quantify association between clusters and predicted income tiers, and prints short textual descriptions per cluster.

**Reporting Artifacts**
- `metrics_grouped_bar.png` – weighted metrics per classifier.
- `clusters_stacked_income.png` – stacked income category distribution by cluster.
- `silhouette_vs_k.png` – silhouette score sweep across candidate `k` values.
- `corr_heatmap_top_features_clean.png` – top feature correlations with the encoded income target.

## Extending the Project

- Swap in additional classifiers (e.g., gradient boosting) within the `models` dictionary to broaden the benchmark.
- Parametrise the Excel path and output directory via command-line arguments or environment variables for more portable execution.
- Persist intermediate artifacts (encoders, scalers) with `joblib` if you plan to score new data outside this script.
- Augment the clustering workflow with alternative algorithms (DBSCAN, hierarchical) or richer feature selection strategies.

## Data Stewardship
